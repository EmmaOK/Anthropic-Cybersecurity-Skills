# Conventions (always in effect)

Imported by the root `CLAUDE.md`, so this applies every session. Rationale for these
choices lives in `docs/DECISIONS.md`.

## Security Conventions

When writing or modifying scripts, follow the hardening conventions applied across the library
(ADR-0008):

**TLS verification** — never hard-disable TLS. Use:
```python
VERIFY_TLS = os.environ.get("SKIP_TLS_VERIFY", "").lower() not in ("1", "true", "yes")
requests.get(url, verify=VERIFY_TLS)
```
Set `SKIP_TLS_VERIFY=1` only for self-signed certs in lab environments.

**Credentials** — never hard-code. Read from env vars, e.g. `HARBOR_PASSWORD`,
`NEO4J_PASSWORD` (falls back to `bloodhound`), `KISMET_USERNAME` / `KISMET_PASSWORD`.

**`pickle.load`** — only on trusted input; annotate with `# nosec B301` and a trusted-source
comment.

A static audit of all scripts/SKILL.md files is saved to `skill_security_audit.json` (many LOW
findings are false positives from detection-rule content).

## Generated / Auto-maintained Files — do not hand-edit

- **`index.json`** — autogenerated skill catalog; regenerate via CI (`update-index.yml`), never
  edit by hand (ADR-0005). Source of truth for the skill inventory; prose counts are approximate.
- **`mappings/attack-navigator-layer.json`** — pre-built ATT&CK Navigator heatmap.
- **`.claude-plugin/marketplace.json`** — version bumped automatically by
  `sync-marketplace-version.yml` on GitHub release (ADR-0010).

## CI Workflows

| Workflow | Trigger | Purpose |
|---|---|---|
| `validate-skills.yml` | Push/PR touching `skills/` | Validates all SKILL.md frontmatter |
| `update-index.yml` | Push to `main` or manual | Regenerates `index.json` |
| `sync-marketplace-version.yml` | GitHub release published | Bumps plugin version in marketplace.json |

All workflows use inline Python 3 on `ubuntu-latest` — no npm or Makefile (ADR-0006).
